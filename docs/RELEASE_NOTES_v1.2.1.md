# Dukkan v1.2.1

إصدار إصلاحي لعملية الإعداد الأول لسوق الضنية المركزي.

## الإصلاح

- تصحيح رقم المراجعة الأول لقاعدة SQLite الجديدة حتى يُحفظ حساب المدير والنشاط من أول محاولة.
- دعم آمن لإكمال الإعداد عندما توجد قاعدة محلية فارغة من تشغيل سابق.
- إضافة اختبار أصلي يمنع تغيير بيانات غير مسموحة أثناء إنشاء أول مدير.

## الترقية

ثبّت الإصدار 1.2.1 فوق الإصدار السابق ثم افتح البرنامج وأكمل إعداد النشاط. لا تحتاج إلى حذف قاعدة البيانات أو إعادة تثبيت Windows.

## التحقق

يمر الإصدار باختبارات الواجهة والمتصفح وRust وقاعدة SQLite، ثم يُبنى Windows Installer ويُثبت ويُشغّل آليًا قبل نشره.
