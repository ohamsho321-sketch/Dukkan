# Dukkan v1.2.0

إصدار الأمان والمخزون المتقدم لسوق الضنية المركزي.

## الجديد

- بوابة جلسة أصلية في Tauri لكل عملية حفظ حساسة.
- تحقق داخل Rust من الأسعار والكميات والخصومات والإجماليات والمخزون قبل قبول العملية.
- صلاحيات دقيقة تمنع الكاشير من تعديل المنتجات أو الأسعار أو الإعدادات أو بيانات الإدارة.
- حماية تسجيل الدخول بقفل مؤقت بعد خمس محاولات فاشلة.
- تشديد إعدادات SQLite ومنع ملفات الأسرار وقواعد التشغيل من دخول الإصدار.
- تتبع الدفعات وتواريخ الصلاحية والتكلفة التاريخية وحركات الإتلاف والإرجاع للمورد.
- سنوات مالية وإقفال سنوي ونسخ احتياطي إلزامي قبل الإقفال.
- تحسينات واسعة على لوحة النشاط والفواتير والمخزون والتقارير والواجهة العربية.

## الترقية

أنشئ نسخة احتياطية من داخل الإعدادات، أغلق Dukkan، ثم شغّل ملف تثبيت الإصدار 1.2.0. يحتفظ التطبيق بقاعدة البيانات المحلية ويرقيها تلقائيًا.

## التحقق

يمر الإصدار بفحص التنسيق، واختبارات الواجهة والوحدات، واختبارات المتصفح، واختبارات Rust وقاعدة SQLite، ثم يُبنى Windows Installer ويُثبت ويُشغّل آليًا على Windows قبل إضافته إلى صفحة الإصدار.

تفاصيل نموذج الحماية: [تطبيق الحماية](SECURITY_IMPLEMENTATION.md).
