# تطبيق الحماية في Dukkan

الإصدار 1.2.0 يعامل واجهة WebView كمدخل غير موثوق، رغم أن البرنامج يعمل محليًا دون خادم أو سحابة. قاعدة SQLite وطبقة Rust في Tauri هما المصدر المعتمد للبيانات.

## المفاتيح والبيئة

- لا توجد مفاتيح API أو كلمات مرور قواعد بيانات داخل الواجهة أو المستودع.
- ملفات `.env` وقواعد SQLite وملفات السجل مستثناة من Git.
- يفشل بناء الإصدار إذا وجد ملف أسرار أو قاعدة بيانات تشغيلية متتبعة داخل المستودع.
- لا يستخدم البرنامج Supabase أو Cloudflare Workers؛ لذلك لا توجد مفاتيح عامة أو خاصة لهذه الخدمات.

## التحقق الأصلي من البيانات

- كل حفظ في نسخة سطح المكتب يمر عبر أمر Tauri محمي بجلسة أصلية.
- طبقة Rust تتحقق من النطاق الرقمي الآمن والأسعار والكميات والخصومات والمدفوعات.
- يُعاد التحقق من مجموع الفاتورة، المخزون، الدفعات، رصيد العميل وحركات المخزون قبل قبول الحفظ.
- يرفض التطبيق أي سعر معدل من أدوات الواجهة وأي بيع يتجاوز المخزون المتاح.

## تسجيل الدخول والصلاحيات

- كلمات المرور مشتقة باستخدام PBKDF2-SHA256 مع 600,000 دورة وملح مستقل لكل مستخدم.
- الجلسة محفوظة في ذاكرة التطبيق الأصلي ولا تُحفظ في localStorage أو النسخة الاحتياطية.
- تُراجع صلاحية الحساب وحالته وبصمة كلمة المرور عند كل عملية حساسة.
- المدير يستطيع إدارة المنتجات والموردين والإعدادات والمخزون والنسخ الاحتياطية.
- الكاشير يستطيع فقط إنشاء فاتورة محسوبة، إضافة عميل، أو تسجيل دفعة عميل صحيحة.

## حماية البيانات المحلية

- SQLite تستخدم `foreign_keys`, وWAL، و`trusted_schema = OFF`، و`secure_delete = ON`.
- الحفظ ذري مع رقم مراجعة لمنع الكتابة فوق تغييرات أحدث.
- توجد سياسة محتوى CSP تمنع تحميل سكربتات أو موارد خارجية غير مصرح بها.
- البيانات تخص مستخدم Windows الحالي وتُحفظ داخل مجلد بيانات التطبيق؛ لا توجد قاعدة مشتركة عن بُعد أو صفوف لمستخدمين آخرين، لذلك RLS السحابية غير مطبقة.

## الحد من محاولات الدخول

- تُسجل المحاولات الفاشلة داخل ذاكرة طبقة Rust.
- بعد خمس محاولات فاشلة خلال 15 دقيقة يُقفل اسم المستخدم لمدة دقيقة.
- رسائل الفشل لا تكشف هل اسم المستخدم موجود أم لا.

## حدود الحماية

هذا إصدار محلي يعمل تحت حساب Windows. الحماية تمنع تلاعب الواجهة وتفرض الصلاحيات داخل التطبيق، لكنها لا تستبدل حماية حساب Windows أو تشفير القرص. يجب تفعيل كلمة مرور Windows وBitLocker عند حفظ بيانات حساسة على جهاز مشترك.
