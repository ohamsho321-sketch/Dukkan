# Dukkan v1.2.2

إصدار نقطة البيع والباركود وصلاحيات موظف المبيعات.

## الجديد

- دعم قارئ الباركود USB مباشرةً: امسح الرمز واضغط القارئ Enter ليُضاف المنتج إلى السلة.
- استمرار البيع اليدوي بالبحث أو الضغط على بطاقة المنتج.
- تحويل دور الكاشير إلى «موظف مبيعات» بصلاحية البيع فقط.
- إخفاء المبيعات الإجمالية والعملاء والمخزون والمشتريات والتكاليف والأرباح عن موظف المبيعات.
- منع موظف المبيعات من إضافة العملاء أو تسجيل الدفعات حتى عبر طبقة الحماية الأصلية.

يعمل البرنامج والبيانات محلياً على جهاز Windows من دون إنترنت. يُفضّل إنشاء نسخة احتياطية قبل التحديث.
